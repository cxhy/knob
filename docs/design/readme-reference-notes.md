## 建议采用的首页结构

1. **项目用途与一个配置例子**：说明哪些运行期参数可调整，以及源码接入后才能复用编译产物。
2. **功能与适用环境**：说明整数、布尔、逻辑使用位置、校验和冻结；列出实际验证的 VCS/UVM 组合。
3. **快速开始**：从获取仓库、准备已有 VCS 环境、编译独立宿主，到两个独立运行目录使用不同配置；给出事务数量和日志判据。
4. **接入成熟工程**：列出 `knob.f`、`src/knob_pkg.sv`，说明相对路径、编译顺序和宿主接入职责，并链接完整指南。随源码分发时保留仓库 LICENSE 文件。
5. **配置与结果规则**：简述默认值、严格键校验、显式 seed 和 UVM 日志/原始退出码分别判定，避免首次使用者误解。
6. **文档、目录与开发验证**：按接入者和维护者的用途给入口，区分可交付库、独立示例与本机回归工具；完整证据通过链接查阅。
7. **问题反馈与许可证**：提供仓库 Issues/PR 入口，说明复现问题所需的最小信息，并链接现有 LICENSE。

## 必须保留的项目事实

依据 [正式规格](knob-spec.md)、[接入指南](integration-guide.md) 和 [当前实现验收](review-fixes-results.md)：

- 已验证环境为 VCS W-2024.09-SP1、UVM 1.2；不增加其他仿真器已兼容的声明。
- 只实现 signed64 整数与布尔文件配置。使用方可以是 sequence、组件或普通 SV 辅助代码，均需显式接入。
- 配置在启动准备期统一加载、校验并冻结；永久不支持运行中修改，暂不支持命令行 knob 覆盖。
- 参数声明或接入代码变化需要编译；只更改已声明参数的配置值时可以复用产物。
- `UVM_FATAL` 的原始进程码可以为 0；日志失败与运行异常分别记录。
- 本机 `scripts/` 和 Makefile 使用项目规定的环境路径。公开快速开始优先使用已有 `examples/host/compile.sh` 与 `run.sh`，由调用者提供自己的 VCS 环境。

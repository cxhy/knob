# UVMF 接入 knob 后的 seed 与配置确认

日期：2026-11-11。Beads：`knob-uv7.8`。用户在 Q19 回访后要求实际确认，本轮据此执行定向接入与 VCS 仿真。

## 结论

在固定 UVMF 2023.4_2 / VCS W-2024.09-SP1 / UVM 1.2 的 ALU 隔离工程中，没有发现 knob 接入导致合法原生 seed 被拒收。seed 101 与 202 均被接受，选定案例的随机结果不同；相同产物、配置和 seed 101 的配置及事务轨迹完全重放。

统一准备放在 test 的 pre_super custom，配置类在 pre_randomize 应用冻结约束输入。保留 ALU 原有子配置再次求解流程，实际记录到两次 pre_randomize；求解结果在 initialize 后与行为开始前均保持有效。该候选接法可在当前示例上工作，不需要修改 knob 核心库或 UVMF 基类。

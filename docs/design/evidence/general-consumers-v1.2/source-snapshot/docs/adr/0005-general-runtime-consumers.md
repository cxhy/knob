# 配置接口面向通用运行期使用方

用户于 2026-11-11 确认，knob 应支持验证环境中显式接入的运行期参数，sequence 是首个应用场景。使用相同的声明、位置句柄和取值接口接入 UVM 组件、普通 SystemVerilog 类及 task/function，避免把配置访问与某个基类或 sequence 启动流程绑定。

本决定扩展 ADR-0002 的使用方范围，保留逐项显式接入和文件输入规则。ADR-0001 的启动前配置、ADR-0004 的登记校验冻结顺序保持不变。框架仍依赖 UVM；不支持修改编译期或 elaboration 常量，也不自动发现字段。更早阶段需要取值时，宿主须先完成全部登记和冻结。

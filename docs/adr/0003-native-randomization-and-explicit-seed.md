# knob 提供约束参数，随机化沿用仿真 seed

用户于 2026-11-11 确认，knob 提供确定的约束参数，由 sequence 使用 SystemVerilog/UVM 原生 `randomize()` 生成随机值；knob 系统不自行抽样或建立独立 seed。每次仿真必须显式传入 VCS 原生 `+ntb_random_seed=<数值>`，遗漏时报错；该参数控制随机状态，与禁止命令行覆盖 knob 配置的范围区分。

为满足可复现要求，验收在编译产物、工具环境、配置、seed、外部输入及随机化调用过程相同的条件下比较随机事务序列，并记录 seed 和最终生效配置。跨工具版本、代码或配置变化后的序列一致性不在保证范围内。该决定保持配置固定，运行中的随机采样不改变 ADR-0001 的边界。

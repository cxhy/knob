# 显式接入 sequence 参数，配置仅由专用文件提供

范围更新：用户后续将配置使用方扩展到通用运行期验证代码，见 [ADR-0005](0005-general-runtime-consumers.md)。以下保留最初决定；显式接入与文件输入规则继续有效。

用户于 2026-11-11 确认，当前目标是调整 UVM 组件相关 sequence 的可配置参数，例如发送数据包的数量。组件或 sequence 作者在每个可调值的入口显式添加 knob 接入代码后统一编译；后续运行通过调整专用 knob 配置文件改变这些参数。

为避免命令行覆盖造成配置混乱，当前仅支持配置文件输入，暂不支持命令行覆盖。该限制是当前范围决定；与 ADR-0001 永久排除运行中动态调参的决定区分。已确认的文件定位、作用域、类型及错误策略以 `docs/design/knob-spec.md` 为规格入口，访谈过程保留于 `docs/design/knob-requirements-notes.md`。
